# pilot-theme-26

This is a PILOT extension that re-skins PILOT (tracking.im2m.ws) to look like gps.im2m.ws.

- `Module.js`: the extension (`Store.pilot_theme_26.Module`). It builds the sidebar and the status tiles and switches between the new and classic look.
- `theme.css`: the theme. Every rule is scoped under `html.pt26`.
- `fonts/`: Open Sans and the gps.im2m.ws `tree` icon font.
- `reference/gps-im2m/`: the captured design of gps.im2m.ws, with `DESIGN.md` (colors, sizes, structure), the original CSS, fonts and screenshots.
  `reference/gps-im2m-reference.zip` holds the same files in one archive.

To register it in PILOT Admin, go to Extensions and use the name `pilot_theme_26` and the URL of this folder (for example GitHub Pages `https://im2mm.github.io/pilot-theme-26/`).
