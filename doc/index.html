PILOT Theme 26 v0.1.0

This extension gives PILOT the look of the gps.im2m.ws platform.

  • Left sidebar: the top menu is replaced by a 90px navy sidebar (logo, user, notifications, one icon per module). Clicking an item opens the same PILOT module as before.
  • Status tiles: the object counters (Total, Moving, Parking, Idle, Problems) appear as colored tiles above the left panel. Click a tile to filter, the same as the header counters.
  • Theme: Open Sans font, blue panel headers and tabs, dense lists, rounded cards, and blue buttons.
  • Classic view: the last icon at the bottom of the sidebar switches back to the normal PILOT look. A button in the header switches the new look back on. The choice is saved in your browser.

Extension name: pilot_theme_26 · Class: Store.pilot_theme_26.Module
